## Рефакторинг без изменения поведения (2026-10-13)
- **Проверка «ничего не сломалось»**: перед правкой снять слепок DOM на демо-подкасте через Playwright
  (innerHTML.length + textContent мобильной, десктопной и печатной зон), после правки сравнить.
  Совпадение побайтово = вёрстка не изменилась. Скриншоты одни не ловят мелкие сдвиги классов.
- **Демо-подкаст не сохраняется в localStorage** (storePersist исключает DEMO_IDS). Прямое открытие
  `/demo/dashboard` после перезагрузки даёт «Подкаст не найден». Для тестов идти с главной
  через «Смотреть демо» и дальше только клиентской навигацией, без reload.
- **Мобильная и десктопная вёрстка карточек мастера** это не одна разметка с адаптивными классами,
  а два варианта с разными классами и структурой. Компоненты в components/setup принимают `layout`
  и воспроизводят оба варианта дословно. Не «унифицировать» их без проверки на ширине 640–767px.
- **react-hooks/set-state-in-effect**: синхронный setState в эффекте обработки OAuth-колбэка ловится
  линтером при выносе в хук. Решение: обернуть в `queueMicrotask`, поведение то же.
- **Классификатор auto-режима блокирует `rm` и `git rm`** даже для отслеживаемых файлов.
  Удаления подтверждать у Саши списком, затем выполнять отдельной командой.

## Автосбор статистики через Playwright MCP (2026-10-14)
- **`browser_evaluate`/`browser_snapshot` с `filename`** кладут файл в cwd (корень репо), а не в
  `.playwright-mcp/`. Результат evaluate это JSON-строка с `\n`. После использования удалять из репо.
- **`browser_run_code_unsafe` без `require`**: файлы с диска читать нельзя. Передавать текст в
  страницу через `ctx.newPage()` + `goto('file://…')` + `pre.textContent`.
- **Скачивания** ловить в run_code: `page.waitForEvent('download')` до клика, затем `saveAs`.
  MCP параллельно кладёт копию в `.playwright-mcp/`.
- **DataLens**: кнопка «…» виджета появляется только по hover на самом виджете; подменю
  «Сохранить как» не попадает в accessibility-снимок, нужен hover в коде. Id виджетов могут
  начинаться с цифры, тогда селектор `[id="5og"]`, а не `#5og`. У каждой вкладки дашборда свои
  фильтры даты и подкаста.
- **Setup-страница**: в DOM две вёрстки, 16 `input[type=file]`; первые 8 относятся к одной
  раскладке и идут в порядке платформ. Заголовки сортировки таблицы эпизодов это `th`, а не
  button; `getByText('Дата')` ловит скрытый мобильный чип.
- **`cd` в Bash меняет cwd сессии** (среда прислала «Environment update»). Использовать
  абсолютные пути вместо `cd`.

## Парсер VK Video (2026-11-18)
- **VK меняет выгрузку без предупреждения**: в ноябре 2026 «Раздел/Подраздел» стали
  «Мой контент/Видео» вместо «Видео/Контент», колонка «Охват» заменена на «Приватность».
  Признак видео искать в обеих колонках, колонки находить по названию, а не по позиции.
- **«Не удалось распознать данные в файле»** означает, что парсер вернул 0 записей.
  Первым делом сравнить шапку и первые строки файла с комментарием в шапке парсера.

## Обновление Next.js и PDF-роут (2026-11-18)
- **`npm install` во время работы `next dev` роняет dev-сервер** (Turbopack теряет `next/package.json`).
  После установки пакетов перезапускать сервер.
- **`npm install next@…` тихо поднимает `eslint-plugin-react-hooks`** (7.0.1 -> 7.1.1), и линтер начинает
  ругаться на setState в эффекте там, где раньше молчал. Плагин закреплён в devDependencies.
- **`next dev` версии 16.4 сам создаёт `AGENTS.md`** в корне и пересоздаёт его при удалении.
- **Проверка PDF-роута без изменения вида отчёта**: снять PDF на демо до правки, после правки сравнить
  `pdftotext` и картинки страниц (`pdftoppm` + `cmp`). Совпадение попиксельно = отчёт не изменился.
- **Демо на мобильной ширине**: «Смотреть демо» не переходит на дашборд, а показывает список подкастов;
  дальше нажимать «Дашборд» у нужной карточки.
